# Área restrita

Esta pasta é reservada para documentos cuja leitura depende de autorização específica.

Exemplos:

- preços, margens e descontos;
- contratos;
- dados pessoais;
- diagnósticos de clientes;
- arquitetura de segurança;
- credenciais e acessos;
- relatórios financeiros;
- planos societários;
- termos de licenciamento ainda não publicados.

Não armazene senhas, chaves de API ou outros segredos diretamente em Markdown.
